# Yeelds

Yeelds [yeelds.ai](https://www.yeelds.ai/) is a discovery-first yield platform
for DeFi power users: curated vaults across Ethereum, Arbitrum & Base with yield
decomposition (organic vs. incentive), raw risk signals, and risk grades.

## Packages

| Package                                              | Name          | Description                                       |
| ---------------------------------------------------- | ------------- | ------------------------------------------------- |
| [`packages/sdk`](./packages/sdk/README.md)           | `@yeelds/sdk` | Typed client for the Yeelds backend API.          |
| [`packages/ui`](./packages/ui/README.md)             | `@yeelds/ui`  | Design system: theme and shared React components. |
| [`packages/frontend`](./packages/frontend/README.md) | `frontend`    | Next.js App Router app.                           |
| [`packages/registry`](./packages/registry/README.md) | `registry`    | Yeelds registry for chains and protocols.         |
